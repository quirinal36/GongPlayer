# 기능 명세

첫 버전(MVP)이 하는 일을 정합니다. 여기 없는 기능은 만들지 않습니다. 넣고 뺀 기준은 [PHILOSOPHY](PHILOSOPHY.md)에 있습니다.

## 화면

창 전체가 영상입니다. 영상은 비율을 유지한 채 창에 맞추고, 남는 곳은 검정으로 채웁니다. 컨트롤 바는 영상 아래쪽에 겹쳐서 그립니다.

```
┌────────────────────────────────────────────────────────────┐
│ 1.5×                                                       │  ← OSD (1초 뒤 사라짐)
│                                                            │
│                          영상                              │
│                                                            │
│  ━━━━━━━━━━━━━━●────────────────────────────────────────   │  ← 탐색 바
│  ⏪  ▶  ⏩  반복   12:34 / 1:23:45        1.0×  🔊━━━  ⛶   │  ← 컨트롤 바
└────────────────────────────────────────────────────────────┘
```

컨트롤 바에는 다음 요소가 있습니다.

| 요소 | 동작 |
|---|---|
| 탐색 바 | 클릭하면 그 위치로 이동. 끄는 동안은 키프레임 단위로 미리 보여 주고, 놓으면 정확한 위치로 이동 |
| 뒤로 / 앞으로 | 5초 이동 |
| 재생 / 일시정지 | 전환 |
| 반복 | 현재 영상의 무한 반복을 전환합니다. 켜져 있으면 글자 아래에 점이 나타납니다. |
| 시간 | `현재 / 전체` 표시. 조작 없음 |
| 배속 | 클릭할 때마다 1× → 1.25× → 1.5× → 2× → 1× 순환 |
| 음량 | 아이콘 클릭은 음소거, 슬라이더로 조절 |
| 전체화면 | 전환 |

## 조작

모든 기능에 키가 있습니다.

| 기능 | 키 | 마우스 |
|---|---|---|
| 재생 / 일시정지 | `Space`, `K` | 영상 클릭 |
| 현재 영상 무한 반복 켜기 / 끄기 | `L` | 반복 버튼 클릭 |
| 5초 뒤로 / 앞으로 | `←` / `→` | 컨트롤 바 버튼 |
| 30초 뒤로 / 앞으로 | `Shift`+`←` / `Shift`+`→` | |
| 처음으로 | `Home` | |
| 배속 한 단계 내림 / 올림 | `[` / `]` | 배속 표시 클릭 |
| 1배속으로 복귀 | `Backspace` | |
| 음량 5% 올림 / 내림 | `↑` / `↓` | 휠 |
| 음소거 | `M` | 음량 아이콘 클릭 |
| 전체화면 전환 | `F`, `Enter` | 영상 더블클릭 |
| 전체화면 해제 | `Esc` | |
| 파일 열기 | `Ctrl`+`O` | 창에 끌어다 놓기 |

배속 단계는 0.5, 0.75, 1, 1.25, 1.5, 1.75, 2, 3, 4배입니다. 모든 단계에서 음정을 유지합니다.

## 동작 규칙

- **파일 열기**: 명령줄 인자(탐색기 더블클릭), 끌어다 놓기, `Ctrl`+`O` 세 가지입니다. 열자마자 재생을 시작합니다.
- **창 크기**: 영상 원본 크기로 엽니다. 화면의 80%를 넘으면 비율을 유지하며 줄입니다.
- **창 제목**: 파일 이름입니다.
- **자동 숨김**: 재생 중 2초 동안 입력이 없으면 컨트롤 바와 마우스 커서를 숨깁니다. 일시정지 중에는 숨기지 않습니다.
- **OSD**: 배속, 음량, 탐색을 바꾸면 왼쪽 위에 `1.5×`, `음량 60%`, `+5초`처럼 1초 동안 표시합니다.
- **파일 끝에서** 기본으로 마지막 프레임에서 멈춥니다. 다시 재생을 누르면 처음부터 재생합니다.
- **무한 반복**을 전환하면 화면에 ‘반복 켜짐’ 또는 ‘반복 꺼짐’을 표시합니다. 켜 두면 현재 영상이 끝날 때마다 처음부터 재생합니다. 이미 끝난 영상에서 켜면 바로 다시 재생합니다. 새 파일을 열면 반복은 꺼집니다.
- **빈 상태**: 파일 없이 실행하면 "파일을 끌어다 놓거나 Ctrl+O"만 표시합니다.
- **오류**: 화면 가운데에 한 줄로 표시합니다. 대화상자는 띄우지 않습니다.
- **절전**: 재생 중에는 화면이 꺼지지 않게 합니다. 일시정지하면 풀어 줍니다.
- **상태 저장**: 하지 않습니다. 실행할 때마다 음량 100%, 1배속으로 시작합니다.
- **고해상도 화면**: 모니터별 DPI에 맞춰 컨트롤을 그립니다.

## 설치와 Windows 통합

- 기본 공개 배포 경로는 Microsoft Store의 MSIX 패키지입니다 ([DISTRIBUTION](DISTRIBUTION.md)).
- 앱 실행에 관리자 권한이나 별도 코덱 설치를 요구하지 않습니다.
- 시작 메뉴에서 실행하고 Windows 설정에서 제거할 수 있어야 합니다.
- 지원 확장자의 파일 연결은 패키지 매니페스트에 선언합니다. 기본 플레이어 선택은 사용자에게 맡깁니다.
- 탐색기의 "연결 프로그램"으로 연 파일도 명령줄로 연 파일과 같은 재생 동작을 합니다. 패키지의 파일 활성화 경로는 M0에서 확인합니다.
- Store 버전의 업데이트는 Store에 맡깁니다. 플레이어에 업데이트용 서비스나 상주 프로세스를 추가하지 않습니다.

## 지원 포맷

| 구분 | 지원 |
|---|---|
| 컨테이너 | MP4, MOV, MKV, WebM, TS, AVI |
| 영상 | H.264, HEVC (8bit, 10bit), AV1, VP9 |
| 소리 | AAC, MP3, AC-3, E-AC-3, Opus, Vorbis, FLAC, PCM |

- 하드웨어 디코딩은 GPU가 지원하는 포맷에서만 됩니다. 나머지는 소프트웨어로 디코딩합니다.
- AV1 소프트웨어 디코딩에는 `dav1d`가 필요합니다. 넣을지는 [DECISIONS](DECISIONS.md)의 미결 항목입니다.
- HDR 영상은 SDR로 변환해 표시합니다.
- 소리가 스테레오보다 많은 채널이면 출력 장치에 맞춰 다운믹스합니다.
- 소리 트랙이 여러 개면 파일이 기본으로 지정한 트랙을 재생합니다.

## 하지 않는 것

| 기능 | 이유 |
|---|---|
| 재생목록, 라이브러리, 최근 파일 | 파일 관리는 탐색기의 일입니다 |
| 자막 | 글꼴과 렌더링 의존성이 크고 매번 쓰는 기능이 아닙니다 |
| 스트리밍, URL 재생 | 네트워크 스택과 버퍼링 UI가 필요합니다 |
| 영상 필터, 색 보정, 이퀄라이저 | 재생이 아니라 편집입니다 |
| 설정 화면 | 원칙 8 |
| 스크린샷, 구간 반복, 녹화 | 볼 때마다 쓰는 기능이 아닙니다 |
| 스킨, 테마 | 화면의 주인은 영상입니다 |

## 나중 후보

MVP 뒤에 실제로 불편을 겪으면 검토합니다. 넣을 때는 [PHILOSOPHY](PHILOSOPHY.md)의 세 질문을 다시 통과해야 합니다.

- 자막 (SRT, 내장 자막)
- 소리 트랙 선택
- 이어 보기, 음량 기억
- 한 프레임씩 이동
- 같은 폴더의 다음 파일로 넘어가기
- HDR 디스플레이 출력
- 인터레이스 영상 처리
- ARM64 빌드
