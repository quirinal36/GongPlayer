# GongPlayer

코덱을 따로 설치하지 않아도 HEVC를 포함한 동영상을 바로 재생하는 Windows용 동영상 플레이어입니다. 재생에 꼭 필요한 기능만 넣고, 그 대신 가장 빠르고 가장 가볍게 만드는 것이 목표입니다.

> **상태 (2026-11-13): 개발 중입니다.** 재생, 소리 동기, 탐색, 배속, 컨트롤 바까지 동작하고 개발 PC에서 합성 영상으로 확인했습니다. 실제 영상 세트 검증, 최소 구성 FFmpeg, 개발용 패키지 설치 확인, Store 제출이 남았습니다. 단계별 진행과 확인한 범위는 [로드맵](docs/ROADMAP.md)에 있습니다. 빌드 방법은 [BUILD](docs/BUILD.md)의 "빠른 시작"을 보세요.

## 왜 만드는가

Windows는 HEVC 코덱을 기본으로 싣지 않습니다. 그래서 아이폰이나 요즘 카메라로 찍은 영상을 기본 앱으로 열면 재생되지 않거나, 유료 확장을 사라는 안내가 나옵니다.

GongPlayer는 디코더(FFmpeg)를 앱에 포함하고, 가능하면 GPU 드라이버에 직접 디코딩을 맡깁니다. 그래서 PC에 어떤 코덱이 깔려 있는지와 무관하게 재생하는 것이 목표입니다.

## 하는 것과 하지 않는 것

| 하는 것 | 하지 않는 것 |
|---|---|
| 파일 열기 (더블클릭, 끌어다 놓기) | 재생목록, 라이브러리 |
| 재생 / 일시정지 | 자막 |
| 앞으로 / 뒤로 이동, 탐색 바 | 스트리밍, 네트워크 재생 |
| 배속 (0.5~4배, 음정 유지) | 영상 필터, 이퀄라이저 |
| 음량, 전체화면 | 설정 화면 |

자세한 범위와 조작법은 [기능 명세](docs/SPEC.md)에 있습니다.

## 기술 선택

| 영역 | 선택 |
|---|---|
| 언어 | Rust |
| 디먹싱과 디코딩 | FFmpeg (libavformat, libavcodec) 직접 연동 |
| 하드웨어 디코딩 | D3D11VA |
| 화면 출력 | Direct3D 11 (VideoProcessor, 플립 모델 스왑체인) |
| 소리 출력 | WASAPI |
| 창과 컨트롤 | Win32 + Direct2D, UI 툴킷 없음 |
| 대상 | Windows 10 이상, x86_64 |

각 선택의 이유와 버린 대안은 [결정 기록](docs/DECISIONS.md)에 있습니다.

## 개발과 배포

현재 Windows PC에서 직접 개발하고 실제 재생을 검증합니다. 일반 사용자에게는 **MSIX 패키지를 Microsoft Store에 등록해 배포**하는 것을 기본 경로로 삼습니다. 사용자는 Store에서 설치하고, 업데이트와 제거도 Windows의 표준 흐름을 따릅니다.

단일 exe는 앱 내부 구성의 경량화 목표입니다. 사용자에게 제공하는 설치 패키지와는 구분합니다. Store 외부의 설치 마법사와 코드 서명은 별도 배포 경로로 검토하며, 세부 기준은 [배포 계획](docs/DISTRIBUTION.md)에 있습니다.
