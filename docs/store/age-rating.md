# 연령 등급 설문 답안 (IARC)

파트너 센터 → 제출 → "연령 등급"의 IARC 설문에 답할 때 참고합니다. 설문 문구는 바뀔 수 있으니, 질문의 뜻이 아래와 다르면 앱의 실제 동작(아래 "근거")을 기준으로 답합니다. 최종 답은 게시자가 정합니다.

## 근거가 되는 앱의 동작

- 사용자가 직접 연 PC의 동영상 파일만 재생합니다. 앱 자체에 영상, 이미지, 글 같은 콘텐츠가 들어 있지 않습니다.
- 인터넷에 연결하지 않습니다. 계정, 채팅, 사용자 간 교류, 콘텐츠 공유가 없습니다.
- 위치 정보, 개인정보를 수집하거나 공유하지 않습니다.
- 앱 내 구매, 광고, 도박 요소가 없습니다.
- 웹 브라우저나 검색 엔진이 아닙니다.

## 권장 답

| 질문 | 답 |
|---|---|
| 앱 종류 | 게임이 아님 → "유틸리티, 생산성, 통신 또는 기타 앱" 계열 (사진·동영상 재생 도구) |
| 폭력, 선정성, 비속어, 약물, 공포 등 앱이 보여 주는 콘텐츠 | 없음 (앱에 내장된 콘텐츠가 없음) |
| 사용자 간 상호작용, 사용자 생성 콘텐츠 공유 | 아니요 |
| 사용자 위치 공유 | 아니요 |
| 개인정보 수집·공유 | 아니요 |
| 디지털 상품 구매 | 아니요 |
| 도박, 모의 도박 | 아니요 |
| 제한 없는 인터넷 접근 (웹 브라우저, 검색) | 아니요 |

## 예상 결과

대한민국(GRAC) 전체이용가 수준을 예상합니다. 실제 등급은 설문 결과로 정해집니다.

참고: 사용자가 연 파일의 내용은 사용자의 것이며 앱이 제공하는 콘텐츠가 아닙니다. 설문에 "사용자가 임의의 미디어를 볼 수 있는가" 같은 질문이 따로 있으면, 인터넷이 아니라 사용자의 로컬 파일이라는 점을 기준으로 답합니다.
