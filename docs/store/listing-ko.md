# Microsoft Store 등록 정보 (한국어)

파트너 센터 → GongPlayer → 제출 → "Store 등록 정보" → 한국어에 그대로 붙여 넣습니다. 각 항목의 글자 수 제한은 2026-11 기준 파트너 센터 안내를 따랐고, 입력 화면에서 넘치면 줄입니다.

배포 지역은 한국만입니다 ([DECISIONS](../DECISIONS.md)의 D30). 패키지의 언어가 `ko-KR`이므로 한국어 등록 정보 하나면 됩니다.

## 제품 이름

GongPlayer

## 설명

```text
코덱을 따로 설치하지 않아도 HEVC(H.265)를 포함한 동영상을 바로 재생하는 가벼운 동영상 플레이어입니다.

아이폰이나 요즘 카메라로 찍은 영상을 Windows 기본 앱으로 열면 재생되지 않거나 유료 확장을 사라는 안내가 나오곤 합니다. GongPlayer는 디코더를 앱 안에 함께 담고, 가능하면 그래픽카드가 직접 디코딩하게 해서 PC에 어떤 코덱이 깔려 있는지와 상관없이 재생합니다.

꼭 필요한 기능만 넣고, 그 대신 빠르고 가볍게 만들었습니다.
• 설치 크기 약 8MB, 관리자 권한 없이 설치
• 하드웨어 디코딩을 지원하는 그래픽카드에서는 4K 60fps 영상도 CPU를 거의 쓰지 않음
• 키를 누르면 바로 반응하는 탐색과 배속
• 화면을 가리지 않는 컨트롤: 재생 중에는 2초 뒤 저절로 숨김

조작
• 재생 / 일시정지: Space, K, 영상 클릭
• 5초 이동: ← →, 30초 이동: Shift + ← →, 처음으로: Home
• 배속 0.5~4배(음정 유지): [ ], 1배속으로: Backspace
• 음량: ↑ ↓ 또는 마우스 휠, 음소거: M
• 전체화면: F, Enter 또는 더블클릭, 해제: Esc
• 파일 열기: 탐색기에서 연결 프로그램으로 열기, 창에 끌어다 놓기, Ctrl + O

지원 형식
• 컨테이너: MP4, MOV, MKV, WebM, TS, AVI
• 영상: H.264, HEVC(8·10bit), AV1, VP9
• 소리: AAC, MP3, AC-3, E-AC-3, Opus, Vorbis, FLAC, PCM
그래픽카드가 지원하지 않는 형식은 CPU로 디코딩합니다. HDR 영상은 SDR로 바꿔 보여 줍니다.

개인정보
GongPlayer는 인터넷에 연결하지 않으며, 어떤 정보도 수집하거나 저장하지 않습니다. 광고와 앱 내 구매가 없습니다.

오픈소스
GongPlayer는 Mozilla Public License 2.0으로 공개된 오픈소스입니다. 소스 코드: https://github.com/quirinal36/GongPlayer
```

## 제품 기능 (항목별 입력, 최대 20개)

```text
코덱 설치 없이 HEVC(H.265) 동영상 재생
그래픽카드 하드웨어 디코딩(D3D11VA)으로 낮은 CPU 사용
AV1, VP9, H.264 지원, 하드웨어가 없으면 CPU로 디코딩
0.5배에서 4배까지 음정을 유지하는 배속
키를 누르면 바로 반응하는 5초·30초 탐색
재생 중 자동으로 숨는 컨트롤 바
모든 기능을 키보드로 조작
HDR 영상을 SDR로 변환해 표시
5.1채널 소리를 스테레오로 다운믹스
고해상도 모니터별 배율에 맞춘 컨트롤
인터넷 연결과 데이터 수집 없음
관리자 권한 없이 설치, 약 8MB
```
